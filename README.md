# PowerBI_File_Finder

Website to parse through PowerBI pages and bookmarks, helping translate meaningless folder names to the meaningful display names. Simply upload the .pbip files to the website, and select which pages and bookmarks you want, and everything will be downloaded easily for you to use!

This is useful for teams that have multiple people working on different PowerBI pages for the same dashboard. A common pitfall for people that are collaborating like this is that it is difficult to transfer both pages and bookmarks effectively. One solution is to convert the .pbix files to .pbip files and manually transfer the relevant pages and bookmarks into the correct folders. Unfortunately, each folder is not named meaningfully according to their display names, which is the issue that this website solves for.

You can simply transfer the relevant pages and bookmarks from the donor .pbip files to the recipient .pbip files, effectively transferring both!
